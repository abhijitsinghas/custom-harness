# Design Tokens JSON Schema v1.0

> Canonical schema for machine-readable design tokens. Generated by the `design-token-extractor` skill from Stitch HTML mockups.

## Top-level structure

```json
{
  "schema_version": "1.0",
  "source": "stitch-html",
  "source_directory": "<path-to-stitch-mockups>",
  "generated_at": "<ISO-8601 timestamp>",
  "screens_extracted": <integer>,
  "warnings": ["<warning messages>"],
  "colors": { ... },
  "typography": { ... },
  "spacing": { ... },
  "borderRadius": { ... },
  "components": { ... },
  "screens": [ ... ]
}
```

## typography

```json
{
  "typography": {
    "h1": {
      "family": "Lora",
      "size": 24,
      "lineHeight": 32,
      "weight": "w600"
    },
    "h2": {
      "family": "Lora",
      "size": 18,
      "lineHeight": 24,
      "weight": "w600"
    },
    "body": {
      "family": "Inter",
      "size": 16,
      "lineHeight": 24,
      "weight": "w400"
    },
    "label": {
      "family": "Inter",
      "size": 14,
      "lineHeight": 20,
      "weight": "w600"
    },
    "caption": {
      "family": "Inter",
      "size": 12,
      "lineHeight": 16,
      "weight": "w400"
    },
    "mono": {
      "family": "JetBrainsMono",
      "size": 12,
      "lineHeight": 16,
      "weight": "w400"
    }
  }
}
```

- `family` — Google Fonts family name or system font name
- `size` — number, in logical pixels (dp)
- `lineHeight` — number, in logical pixels (dp)
- `weight` — Flutter FontWeight string: `w100` through `w900`

## spacing

```json
{
  "spacing": {
    "xs": 4,
    "sm": 8,
    "md": 12,
    "lg": 16,
    "xl": 24,
    "xxl": 32,
    "baseGridUnit": 8
  }
}
```

All values in logical pixels (dp). Every value must be a multiple of `baseGridUnit`.

## borderRadius

```json
{
  "borderRadius": {
    "default": 4,
    "sm": 8,
    "md": 12,
    "lg": 16,
    "xl": 24,
    "full": 9999
  }
}
```

All values in logical pixels (dp). `full` represents a pill/capsule shape.

## Usage in Flutter code

### Theme generation

```dart
// Read design_tokens.json
final tokens = DesignTokens.fromJson(json);

// Generate ColorScheme
final colorScheme = ColorScheme(
  brightness: Brightness.light,
  primary: Color(int.parse(tokens.colors.light.accent.replaceFirst('#', '0xFF'))),
  surface: Color(int.parse(tokens.colors.light.surface.replaceFirst('#', '0xFF'))),
  // ...
);

// Generate TextTheme
final textTheme = TextTheme(
  headlineLarge: GoogleFonts.lora(
    fontSize: tokens.typography.h1.size,
    fontWeight: tokens.typography.h1.weight.toFontWeight(),
    height: tokens.typography.h1.lineHeight / tokens.typography.h1.size,
  ),
  // ...
);

// AppSpacing
abstract class AppSpacing {
  static const double xs = 4;
  static const double sm = 8;
  static const double md = 12;
  static const double lg = 16;
  static const double xl = 24;
  static const double xxl = 32;
}
```

### Widget usage

```dart
// CORRECT — referencing design tokens
Container(
  color: Theme.of(context).colorScheme.primary,
  padding: const EdgeInsets.all(AppSpacing.lg),
)

// WRONG — hardcoded values
Container(
  color: Color(0xFF0D7377),
  padding: const EdgeInsets.all(16),
)
```

## Extension

To add a new token category (e.g., animations, breakpoints):

1. Add the new section to this schema document
2. Update the `stitch-html-parser` to extract relevant values from Stitch HTML
3. Update the `design-token-extractor` to include the new section in output
4. Update relevant agents (planner, feature-agent) to reference the new category
